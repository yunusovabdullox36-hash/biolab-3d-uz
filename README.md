# BioLab — 3D anatomiya

O‘zbek tilidagi interaktiv biologiya platformasi. React, Three.js va Framer Motion asosida qurilgan.

## Imkoniyatlar

- 360° aylantiriladigan 3D organlar va skelet modeli
- Hoverda qisqa, bosilganda batafsil ma’lumot
- 10 savollik interaktiv test va natija
- Qiziqarli biologik faktlar
- Mobil va desktop ekranlarga mos dizayn

## Ishga tushirish

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

> Loyiha o‘quv maqsadida yaratilgan. 3D model tibbiy diagnostika uchun mo‘ljallanmagan.
